🚀 如何使用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  安装 Unity
    • 下载 Unity Hub：https://unity.com/download
    • 安装 Unity 2022.3 LTS
    • 勾选 "WebGL Build Support"

2️⃣  打开项目
    • Unity Hub → Open → 选择 unity3d 文件夹
    • 等待资源导入完成

3️⃣  启动后端
    cd /workspace/backend
    npm install
    npm start
    （服务器运行在 http://localhost:3001）

4️⃣  运行游戏
    • 在 Unity Editor 中打开场景
    • 点击 Play 按钮
    • 或构建 WebGL 版本
